// 01 the problem

The spec-sheet problem

Most model coverage tells you what a model can do on hardware you will never own. That number doesn't help you pick what to run tonight.

Benchmarks run in a datacenter

Headline scores come off multi-GPU servers. Quantized to fit 16GB, the same model behaves differently.

Launch day, no numbers

Every release is "a new frontier." Few posts tell you the quant, the context length or the tokens per second you'll actually get.

VRAM is the real limit

Parameter count, quant and context all draw from the same 16GB. Every test here starts from that budget.

// 02 the method

Every test is a run you can repeat
